# Superstore Analytics Dashboard - README

## Overview
This project presents an interactive analytics dashboard for a fictional Superstore, providing key insights into sales, profit, and order returns across different regions, categories, and time periods.

## What I Did

- **Data Visualization**: Created a dashboard displaying sales, profit, and return rates with year-over-year comparisons.
- **Regional & Category Analysis**: Visualized sales and profit by region and product category to identify top performers.
- **Time Series Trends**: Included a monthly sales trend chart to highlight seasonality and growth.
- **Geographical Insights**: Mapped profit distribution by state for geographic analysis.
- **Interactive Filters**: Added filters for customer, region, and category to enable dynamic exploration of the data.

## Key Insights

1. Sales grew by 47.16% year-over-year, reaching $2.33M.
2. The West region led in sales, while Technology was the top-performing category.
3. The percentage of returned orders decreased by 2.95% compared to the previous year.

*Dashboard created using Microsoft Power BI.*
